Proyectos Destacados

SGI Librería el Saber — Sistema de Gestión de Inventario Full-Stack
React 19 · Vite 7 · Node.js 20 · Express 5 · MySQL · Jest · Railway + Vercel
  • API REST modular de 10 recursos (libros, ventas, kardex, clientes, proveedores, usuarios y catálogos) con autenticación JWT, control de acceso por roles, contraseñas cifradas con bcrypt, cabeceras de seguridad con Helmet, límite de peticiones por IP y consultas preparadas contra inyección SQL.
  • Integridad de los datos: las ventas y los movimientos de kardex se escriben dentro de transacciones MySQL con rollback, de modo que el stock nunca queda descuadrado si un paso falla a mitad de camino.
  • 63 pruebas automatizadas con Jest y Supertest, repartidas en 10 suites que cubren inicio de sesión, ventas, kardex, permisos por rol, catálogos y carga de imágenes.
  • Frontend SPA con React Router 7, rutas protegidas por rol, paginación reutilizable y tablero de indicadores con Recharts; cliente Axios centralizado cuyos interceptores inyectan el token y cierran la sesión de forma global ante un 401.
  • Rendimiento: división del paquete con Vite para que las librerías pesadas de exportación (xlsx, jsPDF) solo se descarguen al generar reportes, compresión gzip de las respuestas y límite de tamaño del payload JSON.
Sistema de Gestión de Parqueaderos Desktop
Python · PyQt5 · MySQL · PyInstaller · ReportLab / openpyxl / matplotlib
  • Aplicación de escritorio por capas (modelos, interfaz, acceso a datos, reportes y autenticación) que asigna celdas de parqueo a funcionarios según tipo de vehículo, cargo y restricción de pico y placa.
  • Regla de negocio resuelta en la base de datos: columnas generadas (STORED) derivan el último dígito de la placa y su paridad, así la clasificación de pico y placa es idéntica para la aplicación y para todos los reportes.
  • Motor de asignación: una celda se comparte entre dos vehículos de paridad de placa opuesta, salvo los cargos con derecho a celda exclusiva; disparadores en MySQL recalculan el estado de cada celda (disponible, parcial o completa) en el mismo momento de la asignación.
  • Módulo de reportes con filtros por sótano, tipo de vehículo y estado, exportación a Excel y PDF, y gráficas de ocupación.
  • Seguridad y entrega: inicio de sesión con contraseñas cifradas (bcrypt) y tres perfiles de usuario; empaquetado con PyInstaller como ejecutable de Windows para instalarlo sin dependencias.
  • Optimización de la interfaz: carga diferida de pestañas, caché en memoria para redibujar sin volver a consultar la base de datos y grilla responsiva de 1 a 8 columnas.
